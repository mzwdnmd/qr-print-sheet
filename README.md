# 二维码打印排版网页

公开页面：<https://mzwdnmd.github.io/qr-print-sheet/>

静态网页，供客户上传带二维码的照片，在浏览器内识别并生成一页九档尺寸的 A4 Word 文档。默认基准边长 1.60 cm，间隔 0.05 cm，共 1.40–1.80 cm。网页保留每张原图的二维码版本、纠错级别和掩模编号，以原图相同的字节重新绘制模块。依照 [卷尺照片测量](MEASUREMENT.md)，中央校徽直径为 10.5 模块，周围白色圆角矩形边长为 11.5 模块、圆角半径为 1 模块。图片自带 1 模块白边，Word 格子四周还留有裁剪空间。下载前逐档检查九个尺寸的可读性。

照片和二维码内容只在当前浏览器中处理，不上传服务器。公开仓库只包含网页源码、校徽和识别程序需要的 WebAssembly 文件。

## 本地运行

```bash
npm ci
npm run dev
```

## 构建

```bash
npm run build
```

运行 `npm run build:pages` 会把可发布文件写入 `docs/`。GitHub Pages 从 `main` 分支的 `/docs` 目录发布；提交新的 `docs/` 文件后网站会更新。Vite 使用相对资源路径，可以发布在仓库子路径。打印时选择实际大小 / 100%。
